# Where to click

The whole workflow as a list, for when you know what you want and just need the
button.

| To | Click |
|---|---|
| Sign in | Username, password, **Sign in** |
| Start a book | **Projects** → **New project** |
| Add a chapter | Project page → **New chapter** |
| Fill in the story bible | Project page → **Story bible** → **Add** in a section |
| Write | Open the chapter; it saves itself |
| Keep a version by hand | Chapter → **Versions** → label → **Snapshot** |
| Go back to an old version | Chapter → **Versions** → **Restore** |
| Add or test a writer | **Writers** → **Add writer** → **Test writer** |
| Get the chapter critiqued | Chapter → **Convene the Guild** → tick critics → **Convene** |
| See a passage a note is about | Click the italic quote in the Guild panel |
| Decide on a note | **Accept**, **Edit fix** or **Reject** under it; **Undo** to change your mind |
| Apply the accepted notes | **Revise** → tick the changes → **Accept all** or **Accept selected** |
| Throw a revision away | In the review → **Discard** |
| Approve a story bible change | Guild panel or **Story bible** page → **Approve**, **Edit and approve** or **Reject** |
| Get a draft written | Select text or place the cursor → **Co-write** → writer, instruction → **Ask for a draft** |
| Compare writers | **Co-write** → tick two or three writers → **Compare** |
| Put a draft in | **Insert at cursor** or **Replace selection** |
| See what the Guild did and cost | Chapter → **History** |
| See which writers you accept | **Stats** |
| Change your name or password | Your name at the top right → Account |
| Add an account (admins) | **Users** → **Add an account** |
| Sign out | **Sign out**, top right |
